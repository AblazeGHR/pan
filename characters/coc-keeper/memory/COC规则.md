# COC 克苏鲁神话规则参考

## 角色创建

### 属性
调查员拥有8项基本属性：
- **STR**（力量）：物理力量
- **CON**（体质）：健康和耐力
- **DEX**（敏捷）：身体灵活性和反应速度
- **APP**（外貌）：外表吸引力
- **POW**（意志）：精神力量和意志力
- **SIZ**（体型）：身体大小
- **INT**（智力）：智商和学习能力
- **EDU**（教育）：受教育程度

### 属性投掷
投掷 3D6×5 决定 STR、CON、DEX、APP、POW。
投掷 (2D6+6)×5 决定 SIZ、INT、EDU。

### 衍生属性
- **HP**（生命值）= (CON + SIZ) / 10，向下取整
- **SAN**（理智值）= POW
- **Luck**（幸运）= 3D6×5
- **MP**（魔法值）= POW / 5

## 技能系统

### 技能点数分配
- **职业技能点数** = EDU × 20
- **兴趣技能点数** = INT × 10

### 技能检定规则
- 投掷 d100 ≤ 技能值 → 成功
- **大成功**：投出 ≤ 技能值的 1/5
- **困难成功**：投出 ≤ 技能值的一半
- **极难成功**：投出 ≤ 技能值的 1/5
- **大失败**：技能值 < 50 时投出 96-100；技能值 ≥ 50 时投出 100

### 对抗检定
双方各进行一次技能检定，成功等级更高者获胜。平局时属性更高者胜出。

## 战斗规则

### 先攻
所有参与者投掷 DEX 检定，按成功等级排序。失败者按 DEX 属性排序。

### 战斗动作
每回合可以做一次攻击 + 一次移动/闪避：
- **攻击**：进行格斗或射击技能检定
- **闪避**：用闪避技能对抗攻击
- **战技**：特殊攻击动作（绊倒、缴械等）

### 伤害
- 徒手攻击：1D3 + DB
- 小型武器：1D4 + DB
- 中型武器：1D6 + DB
- 大型武器：1D8 + DB

**DB**（伤害加值）= (STR + SIZ) 决定：
- 2-64: -2
- 65-84: -1
- 85-124: 0
- 125-164: +1D4
- 165-204: +1D6

## 理智系统

### 理智损失
- 看到怪物：0/1D3 到 1D6/1D20 不等
- 阅读神话典籍：1D4 到 2D8
- 目睹同伴死亡：0/1D3

### 疯狂
短期疯狂（1D10 小时）：
1. 失忆
2. 恐惧症
3. 幻觉/妄想
4. 偏执

长期疯狂：
- 持续到治疗完成
- 每次触发事件需重新检定

### 理智恢复
- 完成冒险：+1D6 SAN
- 精神治疗：每月 +1D3 SAN
- 角色成长：提升技能到90%以上 → 永久 +2D6 SAN

## 魔法系统

### 学习法术
- 消耗 INT × 1 小时学习
- 需要 INT 检定成功
- 学习时自动损失 SAN

### 施法消耗
- MP 消耗：法术描述中的 MP 消耗
- SAN 消耗：每次施法损失 1-SAN
- POW 消耗：部分法术永久损失 POW

## 调查规则

### 线索收集
- **侦查检定**：发现隐藏线索
- **图书馆使用**：在档案中查找信息
- **话术/说服**：从 NPC 处获取信息
- **心理学**：判断 NPC 是否说谎

### 时间管理
- 每天约 8-12 小时的调查时间
- 长途旅行消耗天数
- 短期内重复检定降低成功概率
