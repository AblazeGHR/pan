# 跨平台适配计划

> Core 当前约 30 行 Windows 特化代码。改为跨平台不新增模块，只是实现质量提升。

---

## 1. 进程树杀死

**现状**：`taskkill /F /T /PID <pid>`

**改为**：`psutil`（已在 Python 生态中，无额外系统依赖）

```python
import psutil

def kill_process_tree(pid: int):
    try:
        parent = psutil.Process(pid)
        children = parent.children(recursive=True)
        for child in children:
            child.kill()
        parent.kill()
    except psutil.NoSuchProcess:
        pass
```

**影响**：
- `worker.py` `_kill_process_tree()` 和 `_kill_takeover_terminal()` 两个函数
- 消除 ~15 行 `taskkill`/`tasklist` 调用
- 新增 `psutil` 依赖（`requirements.txt`）

---

## 2. 接管终端

**现状**：`powershell.exe -NoExit -Command` + `CREATE_NEW_CONSOLE`

**改为**：`platform_opener()` 函数

```python
import sys, subprocess

def open_terminal(cmd: str, cwd: str):
    if sys.platform == "win32":
        subprocess.Popen(
            ["powershell.exe", "-NoExit", "-Command", cmd],
            cwd=cwd, creationflags=subprocess.CREATE_NEW_CONSOLE,
        )
    elif sys.platform == "darwin":
        # macOS: AppleScript 打开新 Terminal 窗口
        script = f'tell app "Terminal" to do script "{cmd}"'
        subprocess.Popen(["osascript", "-e", script], cwd=cwd)
    else:
        # Linux: 尝试 gnome-terminal，fallback 到 xterm
        try:
            subprocess.Popen(["gnome-terminal", "--", "bash", "-c", cmd], cwd=cwd)
        except FileNotFoundError:
            subprocess.Popen(["xterm", "-e", cmd], cwd=cwd)
```

**影响**：
- `server.py` `api_takeover()` 函数，替换写死的 `powershell.exe` 调用
- ~10 行改动

---

## 3. CLI 可执行文件路径

**现状**：adapter 硬编码 `D:\node_npm\node_global\cbc.cmd`

**改为**：adapter 只指定可执行文件名 `cbc`，路径约定：

- 配置文件中可覆盖：`"cbc_path": "/path/to/cbc"`
- 默认依赖环境变量 PATH（Windows 下 `cbc.cmd` 也在 PATH 里）
- Adapter 内部使用 `shutil.which("cbc")` 查找

**影响**：
- `adapters/cbc/adapter.py` `_CBC_PATH` 改为从配置读取，fallback `shutil.which("cbc")`
- ~3 行改动

---

## 4. 路径处理

**现状**：混用 `\\` 和 `/`

**改为**：全项目使用 `pathlib.Path`，`as_posix()` 用于序列化，`str()` 用于子进程调用

**影响**：全局渐进式修改，不影响功能。

---

## 优先级

跨平台改造放在 **Core 稳定后**（API 不再大改时）一次性做掉。提前引入 `psutil` 反而增加当前迭代的依赖复杂度。
