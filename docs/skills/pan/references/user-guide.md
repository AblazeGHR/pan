# 怎么使用 / 玩转 Pan —— 面向最终用户的标准回答

> **本文档的读者是 meta-agent（SMA 等），正文是发给最终用户看的标准内容。**
>
> **何时用**：最终用户（非 agent、不写代码的人）问你「怎么使用 / 玩转 Pan」「你能干什么」时，按本文正文框架回复——不要抛 MCP 工具名、API、session_id 等开发者术语。
>
> **怎么用**：可以把「正文」整段或按小节发给用户；「回复时的注意事项」一节是给你自己的，不要发给用户。

## 正文（发给用户）

### 开场：Pan 是什么，你怎么用

Pan 是你的「AI 工作室」：你只跟一个总管对话（就是我），我会把你想做的事拆解，派给一支 AI 帮手团队并行干活，再把结果汇总交给你。你不需要学任何命令或工具——**用大白话说清楚你想做什么就行**。

### 1. 直接说你想做什么

任何事都可以直接告诉我，比如：

- 「帮我整理一下这个目录」
- 「写个脚本做数据分析」
- 「调研 XX 主题，写一份对比报告」
- 「把这段代码里的 bug 修掉，并跑通测试」

我会判断这事是我顺手做掉，还是需要请专门的帮手（一个或多个）来做。需要帮手时，创建、派活、盯进度、验收结果都由我负责——不用你操心。

### 2. 任务怎么说，我做得更快更好

说清楚三件事就够了：

1. **目标**：你要什么结果；
2. **范围**：涉及哪些文件 / 目录 / 主题；
3. **边界**：哪些不能碰、格式有什么要求。

对比一下：

| 模糊任务 | 清楚的任务 |
|---------|-----------|
| 「帮我整理一下」 | 「把 D:/photos 里的图片按拍摄月份归档成子文件夹，别删除任何文件，最后给我清单」 |
| 「写个脚本」 | 「写个脚本，把 reports/ 下所有 csv 合并成一个汇总表 merged.csv，空文件跳过」 |
| 「调研一下 XX」 | 「对比 A / B / C 三个方案的优劣，最后给一页纸结论，我明天要用」 |

说不清楚也没关系——先说个大概，我会追问你补充细节。

### 3. 想要专门的帮手？说一声就行

你**不需要**自己动手创建什么：

- 「帮我开一个专门做前端优化的 agent」——我会创建并接管它，以后相关的活都派给它；
- 「这事拆成三个任务并行做」——我会开三个帮手同时干，做完把结果合并给你；
- 不需要时说一声「把那些临时会话清了吧」——我来收尾。

### 4. 进度和结果怎么看

- **在对话里问**：「做得怎么样了？」「第 2 个任务完了吗？」——我随时汇报；
- **看 Dashboard**：网页界面里能看到每个帮手的实时输出和状态（绿色空闲 / 蓝色干活 / 红色出错）；
- 任务完成时，我会主动把汇总结果发给你。

### 5. 不满意？继续说

做完一轮只是开始，你可以：

- 追加要求：「报告再加一节成本对比」；
- 修正方向：「别用方案 A 了，改走 B」；
- 让我合并：「把两个 agent 的结果整合成一份文档」。

帮手会带着之前的上下文继续干，不用从头解释。

### 试一试：一段真实对话

> **你**：帮我把 D:/project/demo/data 这个乱糟糟的目录整理一下，按文件类型分类。
>
> **Pan（我）**：好的。我会请一个专门的 agent 来做：它先扫描目录统计有什么文件，然后按类型建「图片 / 文档 / 数据」等子文件夹归类，只移动不删除，完成后给你一份「什么文件移到哪」的清单。现在开始。
>
> **你**：等等，数据文件别动，只整理图片和文档。
>
> **Pan（我）**：收到，已经把这个要求转给它——数据文件保持原样，只归类图片和文档，完成后一起汇报。

### 进阶（一句话）

用熟之后，想让我长期保留某个专门的会话、给它换更聪明的模型、或让它接入 QQ 随叫随到——直接跟我说就行，我来配置。

## 回复时的注意事项（给 meta-agent，不发给用户）

1. 面向用户回复时禁用：MCP 工具名（`session_create` / `agent_assign` 等）、API / curl / WS、`session_id`、workdir、adapter 等内部术语。
2. 「会话 / agent / Dashboard」可以用（UI 上用户看得到），但主体说法是「我 / 帮手 / 团队」。
3. 用户若表现出开发者意图（想接 API、自己写脚本控制 Pan），再引导其阅读 `docs/USER_MANUAL.md` 与本 skill 其余章节——那些是开发者 / agent 视角的文档。
4. 用户问「Pan 能干什么」时，可参考主 SKILL.md §1–§8 的能力概览，转化成大白话回答，不照搬术语。
