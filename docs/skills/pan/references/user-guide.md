# 怎么使用 / 玩转 Pan —— 面向最终用户的标准回答

> **本文档的读者是 meta-agent（MA，如 SMA 模板会话），正文是发给最终用户看的标准内容。**
>
> **何时用**：最终用户（非 agent、不写代码的人）问你「怎么使用 / 玩转 Pan」「你能干什么」时，按本文正文框架回复——不要抛 MCP 工具名、API、session_id 等开发者术语。
>
> **怎么用**：可以把「正文」整段或按小节发给用户；「回复时的注意事项」一节是给你自己的，不要发给用户。

## 正文（发给用户）

### 开场：Pan 是什么，你怎么用

Pan 可以作为你的「AI 工作室」：你可以直接使用一个会话；配置好总管会话后，也可以让它拆解任务、派给帮手，再验收并汇总结果。已准备好 CLI 和权限时，日常任务通常只需**用大白话说清楚你想做什么**；首次安装和可选通知仍需配置。

### 1. 直接说你想做什么

任何事都可以直接告诉我，比如：

- 「帮我整理一下这个目录」
- 「写个脚本做数据分析」
- 「调研 XX 主题，写一份对比报告」
- 「把这段代码里的 bug 修掉，并跑通测试」

我会判断这事是我顺手做掉，还是需要请专门的帮手（一个或多个）来做。需要帮手时，创建、派活、盯进度、验收结果都由我负责——不用你操心。

### 2. 任务怎么说，我做得更快更好

说清楚三件事就够了：

1. **目标**：你要什么结果；
2. **范围**：涉及哪些文件 / 目录 / 主题；
3. **边界**：哪些不能碰、格式有什么要求。

对比一下：

| 模糊任务 | 清楚的任务 |
|---------|-----------|
| 「帮我整理一下」 | 「把 D:/photos 里的图片按拍摄月份归档成子文件夹，别删除任何文件，最后给我清单」 |
| 「写个脚本」 | 「写个脚本，把 reports/ 下所有 csv 合并成一个汇总表 merged.csv，空文件跳过」 |
| 「调研一下 XX」 | 「对比 A / B / C 三个方案的优劣，最后给一页纸结论，我明天要用」 |

说不清楚也没关系——先说个大概，我会追问你补充细节。

### 3. 想要专门的帮手？说一声就行

总管会话已具备相应权限时，你可以请我代为管理：

- 「帮我开一个专门做前端优化的 agent」——我会创建并接管它，以后相关的活都派给它；
- 「这事拆成三个任务并行做」——我会按可用 CLI、资源和权限安排帮手，并验收结果；
- 不需要时说一声「把那些临时会话清了吧」——我来收尾。

### 4. 进度和结果怎么看

- **在对话里问**：「做得怎么样了？」「第 2 个任务完了吗？」——我随时汇报；
- **看 Dashboard**：网页界面里能看到每个帮手的输出和运行状态；黄色计数是未读完成结果，队列计数表示待投递消息；
- 配置了完成报告订阅时，帮手的结果会进入总管队列，由我继续处理和验收；排队或帮手完成不代表已经验收。

### 常用网页操作

- 找会话：侧栏可搜索会话和工作区，并筛选运行中、未读或有队列消息的会话；Chat 内另有消息历史搜索。
- 清理未读：工作区菜单 **Read all** 标记该工作区成员已读；多选后 **Actions** 可标记所选会话已读、群发或批量开关通知。
- 控制待办：锁住队列条目可暂缓它；**Pause everything** 暂停整个会话队列的后续投递，不会停止正在做的事。支持的会话可用 **Steer** 补充当前任务要求。输入发送后清空并等待确认，结果未确认时不要重复发。
- 收通知：在设置的 **Notification** 中选默认渠道和 QQ 联系人，再点亮会话铃铛。浏览器通知需要页面存活和权限；Windows 通知点击只有 60 秒处理窗口，真实 OS 点击尚未验证。

完整操作与排障见[用户手册](../../../USER_MANUAL.md)。

### 5. 不满意？继续说

做完一轮只是开始，你可以：

- 追加要求：「报告再加一节成本对比」；
- 修正方向：「别用方案 A 了，改走 B」；
- 让我合并：「把两个 agent 的结果整合成一份文档」。

保留的会话可以继续使用已有历史；是否能恢复原生 CLI 上下文取决于所选工具和会话状态。

### 试一试：一段真实对话

> **你**：帮我把 D:/project/demo/data 这个乱糟糟的目录整理一下，按文件类型分类。
>
> **Pan（我）**：好的。我会请一个专门的 agent 来做：它先扫描目录统计有什么文件，然后按类型建「图片 / 文档 / 数据」等子文件夹归类，只移动不删除，完成后给你一份「什么文件移到哪」的清单。现在开始。
>
> **你**：等等，数据文件别动，只整理图片和文档。
>
> **Pan（我）**：收到，已经把这个要求转给它——数据文件保持原样，只归类图片和文档，完成后一起汇报。

### 进阶（一句话）

用熟之后，想让我长期保留某个专门的会话、给它换更聪明的模型、或让它接入 QQ 随叫随到——直接跟我说就行，我来配置。

## 回复时的注意事项（给 MA，不发给用户）

1. 面向用户回复时禁用：MCP 工具名（`session_create` / `agent_assign` 等）、API / curl / WS、`session_id`、workdir、adapter 等内部术语。
2. 「会话 / agent / Dashboard」可以用（UI 上用户看得到），但主体说法是「我 / 帮手 / 团队」；MA / TA / Session / Worker 等编排术语只出现在开发者/编排者文档，不进入面向用户的回复。
3. 用户若表现出开发者意图（想接 API、自己写脚本控制 Pan），再引导其阅读 `docs/USER_MANUAL.md` 与本 skill 其余章节——用户手册也适用于直接操作 Dashboard 的普通用户，skill 其余章节适用于高级编排。
4. 用户问「Pan 能干什么」时，可参考主 SKILL.md §1–§8 的能力概览，转化成大白话回答，不照搬术语。
