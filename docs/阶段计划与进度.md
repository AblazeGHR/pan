## 三、首条消息性能优化（已解决，历史）

~~通过克隆"已探索"session 历史上下文注入首次调用，跳过首条冷启动。~~

**当前方案**：`coc-keeper-coldstart` profile（commit `f9a28da`）
- system_prompt 注入权威系统信息：声明权威（禁止验证/探索）、硬性禁止 Bash/Grep/Read/Agent、需要数据直接用 MCP 工具（08-16 起直接调用，无需 ToolSearch）
- 实测：首条消息 ~90s → ~16s（5.6x）（历史：当时经 1 次 `DeferExecuteTool(game_list)`）
- `725e680` 补充：branch session 继承 character 绑定 + MCP 配置 + 跨目录查找 session JSONL

> 注：该 profile 的 prompt 断言"已连接 RuleWhisper MCP"，依赖 `config.json` 的 `plugin_manifests` 配置了 RuleWhisper 插件；未配置时会幻觉调用。
