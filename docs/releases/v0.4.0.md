# Pan v0.4.0 — 第一发布检查点

发布说明已准备，尚未发布；实际发布日期、最终源码 SHA、tag 和 GitHub Release 由 MA 在门禁完成后确认。CHANGELOG 的 2026-10-22 为候选准备日期；若正式发布日期变化，发布前同步修改。

本版本以共享 Action/Group 和扩展后的 MCP 能力作为新的次版本检查点。版本入口为 `packages/core/__init__.py` 的 `__version__ = "0.4.0"`，前端私有包不单独编号。

## 主要变化

- Actions Panel 管理共享 Action/Group：稳定 ID、复制、缓存列表，Group build 生成不可变插件 release，Worker 启动时固定版本。
- Pan CLI 提供启动、退出、重启、状态、诊断、日志和控制台控制；生命周期写入绑定实例身份。
- 持久 Jobs 支持取消、排序、标签及进程命名；模型选择显示 CBC 按模型倍率，导入列表支持原生 CLI Session ID 搜索。
- MCP 增强模型缓存和历史检索、报告订阅状态及原报告批次消费；提供现有 Worker 的延迟重启和只读状态查询。
- Illegal 新消息锁定、显式 Wake、按来源的自动汇报/Force 路由与队列来源/锁定原因展示保持一致。
- 改进原生附件选择器、替身交接提示词覆盖与快捷键录制反馈。

## 可靠性修复

- 跨 Session 并发启动与 branch 的 Worker ID 分配/注册不再因 await 覆盖已有 runtime。
- Kill 成功后按服务 epoch、Worker ID、generation 清理 Session/Worker store，保留后继 runtime；未知身份保守处理。未注册但活着或未知的 owner 不会被误报为已终止，second-writer 门禁保留。
- 修复 Session 摘要水合、Codex branch 谱系、报告/队列投影和 Actions 缓存竞态；CLI guard 保留直接 ASGI 请求任务和流式语义。
- 更新测试 fixture 的 UTF-8、generation、原子持久化、报告策略和 Job 必填字段，并保留原场景负载与失败身份。
