# 普通局域网访问

在电脑本机的 Pan 回环地址打开 App Settings，在现有远程设置区域找到「普通局域网访问（LAN）」。默认关闭；原主入口继续使用原有 loopback 地址，Tailscale 与 Cloudflare Tunnel 可独立同时开启。

1. 选择连接同一局域网的本机 IPv4 地址，例如 `192.168.1.5` 或 `10.x.x.x`。列表也可能包含 VPN 地址，请按实际网卡选择。`0.0.0.0` 表示所有 IPv4 接口，包含 VPN，并不限定为局域网；默认不会选择它。
2. 选择空闲的入口端口（默认 `8780`），保存 LAN 配置。
3. 点击「开启 LAN 访问」，将显示的 `http://<本机地址>:<端口>` 复制到同网设备浏览器。HTTP 局域网页面可能没有剪贴板权限，复制失败时可手动选择地址。
4. 「下次启动 Pan 默认开启 LAN」控制启动恢复。保存配置不改变当前入口；启停即时生效，无需重启 Pan。修改运行中的地址/端口，先关闭当前入口，再开启新配置。

LAN 入口使用原有 HTTP、聊天 WebSocket 与终端处理器，不会改变内部 `PAN_API_URL`、启动真实 provider 或配置 Funnel。监听失败（地址不属于本机、端口占用等）会显示错误并回收失败入口，原主入口仍工作。非法配置不会被默默当作已开启；损坏的 `config.json` 不会被 LAN 设置覆盖。正常关闭会断开此入口连接；进程异常退出后操作系统释放端口，下次启动按保存配置重新绑定。

Pan 没有全站登录保护，HTTP 内容不加密。开启后，能连接此接口的设备可使用聊天与终端，请只在可信网络使用。LAN 入口禁止本机 MCP/terminal-tools/self-queue 身份桥、agent WebSocket、主服务控制、全局设置写入和 managed/readonly 管理；请从本机回环入口操作这些管理功能。它不信任 `X-Forwarded-*` 身份或地址。

「已开启」只表示本机已成功监听，不保证手机能到达。若无法访问，请检查设备是否同网、无线 AP 客户端隔离、所选地址是否正确，以及 Windows 防火墙是否允许该 Python 进程/入口端口。Pan 不会自动修改防火墙、网卡、路由或代理；根据实际防火墙策略可能需要用户自行配置允许规则。

配置保存在 `config.json` 的独立 `lan` 字段：

```json
{"lan": {"startupEnabled": false, "host": "192.168.1.5", "port": 8780}}
```

主启动代码已有旧的 `PAN_HOST` 环境变量，可改变主入口绑定。LAN 设置不修改它；保留主入口回环时，请保持默认 `PAN_HOST=127.0.0.1`。旧环境变量仅改变主入口，不能替代此处的独立热启停和本机管理隔离。
