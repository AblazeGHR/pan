## 优先级 1：首条消息性能优化（session 克隆）——**已由 coldstart profile 解决**

~~通过克隆 "已探索" session 的历史上下文并注入首次调用，跳过首条冷启动。~~

**当前方案**：[`coc-keeper-coldstart` profile](../manifest.json)（commit `f9a28da`）

- 不再走 session 文件克隆；改为在 system_prompt 中注入权威系统信息：
  1. 系统信息声明权威（禁止验证/禁止探索代码库）
  2. 硬性禁止 Bash/Grep/Read/Agent 探索
  3. 需要数据直接用 MCP 工具（ToolSearch → DeferExecuteTool）
- 实测：首条消息 ~90s → ~16s（5.6x），仅 1 次 `DeferExecuteTool(game_list)`
- `725e680` 补充：branch session 继承 character 绑定 + MCP 配置 + 跨目录查找 session JSONL

> 注：该 profile 的 prompt 断言"已连接 RuleWhisper MCP"，依赖 `config.json` 的 `plugin_manifests` 配置了 RuleWhisper 插件；未配置时会幻觉调用（见质量审查"合并前注意"）。
