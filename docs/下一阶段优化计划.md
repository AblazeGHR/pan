## 优先级 1：首条消息性能优化 (session 克隆)

**相关方案**：[session 克隆避免冷启动](./session-克隆避免冷启动.md)

后续消息已通过 `--resume` 优化。但每个新 session 的首条 cbc 调用仍从零探索代码库。
通过克隆 "已探索" session 的历史上下文并注入首次调用，跳过首条冷启动。

**问题**：
- 新 session 首条消息 ~90s（20+ 次本地工具调用：Bash/Grep/Agent 探索 Pan 项目）
- 模型需要探索代码库才能理解 "RuleWhisper is connected"

**方案**：

在 system_prompt 中加入项目背景：
```
系统信息：你正在 Pan CLI Agent 项目中作为 COC 守秘人运行。
Pan 已将 RuleWhisper MCP 服务器 (rulewhisper) 配置并连接。
项目工作目录由 -d 参数指定，不需要探索项目代码结构。
当玩家提出游戏操作请求时，直接使用 RuleWhisper MCP 工具。
```

这样模型不需要探索项目就能直接使用 MCP 工具。

**方案**：

```python

MCP_TIMEOUT = 60  # 首块数据超时

```
