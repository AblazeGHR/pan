## Frontend - Dual Source of Truth

Two frontends coexist long-term:

### Legacy (Vanilla JS)

Source: **`packages/web/ts/app.ts`** (TypeScript)

- **`packages/web/static/js/app.js`** is a **compiled artifact** generated by `npx tsc`. It is gitignored.
- NEVER edit `static/js/app.js` directly. Always edit `ts/app.ts` instead.
- After editing `ts/app.ts`, run `npx tsc` to compile the JS output.

### React SPA

Source: **`packages/web/src/main.tsx`** (TypeScript + React)

- **`packages/web/dist/`** is the Vite build artifact. It is gitignored.
- After editing, run `pnpm build` in `packages/web/` to compile.
- Dev server: `pnpm dev` in `packages/web/` (Vite HMR + proxy to backend)

### Routing

| URL | Frontend | Status |
|-----|----------|--------|
| `/` | Legacy Vanilla | Stable backup |
| `/react/*` | React SPA | Primary development target |

**Backend priority**: Backend API/WS evolves for React first. If backend changes break the legacy frontend, patch `ts/app.ts` to follow — do not constrain backend changes.

### Pre-commit

Pre-commit hook via `git config core.hooksPath scripts` verifies **both** frontends:
- Legacy: `npx tsc` (in `packages/web/`)
- React: `pnpm build` (in `packages/web/`)

## Port Configuration

Service port is configured in `config.json` (gitignored). Each branch has its own:
- `main` branch → port `8768`
- `test` branch → port `8767`

`main.py` reads from `load_config().get("port")`. Environment variable `PAN_PORT` overrides.

## Package Structure

All core logic lives in **`packages/core/`** — do NOT import internal modules directly from other packages.
Every external module communicates with Core exclusively via HTTP/WS APIs exposed through `packages/web/server.py`.
